# 📝 Add A Cheat Sheet

> [!CAUTION]
> Don't edit, remove or manually add *.id files. They are automatically managed for referencing.

> [!TIP]
> You can preview a page (with the css used on the site) with the [preview](https://cheat-sheet.tech/preview)

## 1 - Fork the repo

## 2 - Create base page (index.md)
> [!NOTE]
> this file is required, it should contains minimal information,
juste some resourceours to quicly copy/paste or to reminds.
To add more details or explanation, see the `details.md` file.

Create a page with title `{title}` related to tech `{tech}`,

by creating a `pages/{tech}/{title}/index.md`

## 2 bis - (optional) Create details page (details.md)
> [!NOTE]
> this file is optional, it used to add details or explanation. The page should follow the structure of the `index.md` page,
it should be seen as a 'extended' version of the `index.md` and not as a totaly diferent page.

Create a page with title `{title}` related to tech `{tech}`,

by creating a `pages/{tech}/{title}/details.md`
